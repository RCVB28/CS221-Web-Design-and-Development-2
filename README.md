# CS221 Web Design and Development 2

## Project Overview

A MERN stack e-commerce web application developed for **CS221 – Web Design and Development 2**. The project demonstrates the implementation of user authentication, product browsing, product search, shopping cart functionality, and checkout.

## Requirements Implemented

* **User Authentication**

  * User registration and login
  * JWT-based authentication
  * Password hashing using Bcrypt
  * User state persistence
  * Protected routes

* **Product Browsing**

  * Products fetched from MongoDB
  * Displays product information such as name, image, price, and other metadata

* **Product Search**

  * Search and filter products
  * Allows users to easily find specific products

* **Shopping Cart**

  * Add products to cart
  * Update item quantities
  * Remove items from cart
  * Cart persistence across page refreshes

* **Checkout Process**

  * Displays order summary
  * Calculates the total amount
  * Provides an order/checkout action

## Technologies Used

* **MongoDB** – Database
* **Express.js** – Backend framework
* **React.js** – Frontend
* **Node.js** – Runtime environment
* **JWT** – Authentication
* **Bcrypt** – Password hashing
